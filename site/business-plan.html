Assumptions & provenance

  1. Measured (live prod, deepseek-v4-flash): one chat reply = 5,528 tokens; one full coached game ≈ 16,400 tokens (reconciled against a real 1-game+3-chat session at 33k tokens / $0.0033).
  2. Prices: $0.14/M input (cache-miss), $0.0028/M input (cache-hit), $0.28/M output. Steady-state assumes the ~2k-token system prompt is a warm shared cache-hit. The "2×" rows are a scenario — the announced increase has not landed; v4-flash is still at the old price.
  3. Revenue net: €9.99 → −20% VAT → −15% Play fee = €7.08/mo. Annual €71.99 → ≈€51/yr = €4.25/mo net. Costs converted at ~$1 = €0.92.
  4. Modeled usage: the Free panel's "realistic" row (8 games + 25 chats/mo) is an engaged user; the at-scale table uses a lower blended average (~3 games + 10 chats/mo ≈ €0.010/user) because most signups are light or dormant. Typical Premium = 2 games + 8 chats/day. Ceilings are every daily cap hit for 30 days — a pathological user no real account reaches.
  5. Not a cost, a capacity limit: Stockfish CPU is ~€0.000007/game. The 2-vCPU box caps at ~50–100 concurrently active players before eval queueing, well before tokens become the constraint. AI opponent runs on-device (zero server cost).
